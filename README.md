# Spring Boot Store API

A production-style e-commerce backend built using Java and Spring Boot.

## Features

- User registration and authentication
- JWT authentication
- Access and refresh tokens
- Product management
- Category management
- Shopping cart
- Cart items
- Address management
- Order management
- Product search
- Validation
- DTO-based API design
- MapStruct mapping
- Database migrations with Flyway
- MySQL persistence
- Stripe payment integration
- Swagger/OpenAPI documentation
- Spring Security
